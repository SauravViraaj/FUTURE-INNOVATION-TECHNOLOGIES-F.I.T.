# Future Innovation Technologies (F.I.T.) Website

Responsive single-page company website for **Future Innovation Technologies** showcasing drone/UAV solution areas, robotics and AI, STEM education labs, industries served, process, FAQs and project enquiries.

## Preview locally
Open `index.html` in a browser. No build tools are required.

## Files
- `index.html` — complete responsive site (HTML, CSS and JavaScript)
- `fit-logo.svg` — vector F.I.T.-style logo illustration for this first web draft
- `education-poster.svg` — vector education laboratory visual for the education section

## Before making the website public
1. Replace the placeholder business email, phone and location in `index.html`.
2. Confirm actual drone models, availability, technical specifications, warranties, service and certification claims.
3. The enquiry form currently opens a prefilled email draft. Change `YOUR-EMAIL@example.com` and configure a form backend if you want submissions delivered and stored automatically.
4. Add official privacy policy and legal details before collecting customer enquiries.
5. This repo was private in the supplied screenshot. To publish the site, change repository visibility if desired and enable GitHub Pages in **Settings → Pages**, selecting the `main` branch and `/(root)`.

The two SVG assets here are custom vector stand-ins, not the original image files from the reference screenshot. Replace them with approved original brand assets when possible.
